# Brand identity

> **Exploratory direction, not an approved identity.** The wordmark, logo and
> brand colour are still to be decided. Until they are, interfaces use the
> lowercase text "nebula" in the default sans at normal weight, with no special
> styling.

**nebula:** a connected environment for human and agent work.

## Attributes

| Attribute | How it shows in the product |
|---|---|
| Calm | Restrained colour, little visual noise, no ambient motion |
| Capable | Dense, powerful tools without needless complexity |
| Precise | Exact terminology, aligned layouts, accurate feedback |
| Connected | Relationships and context are always one step away |
| Human | Comfortable reading, accessibility, user agency |
| Adaptive | The same information in the representation each task needs |
| Durable | Design that ages well instead of following trends |

## The name does the work

"Nebula" does not need to be illustrated. Do not use galaxy backgrounds, star
fields, glowing purple borders or orbital animations. The settings page is a
settings page.

## A family, not a collage

Every Nebula application should be recognizable as part of the same family:
- the same shell
- the same tokens
- the same voice ([voice.md](voice.md))
- the same interaction patterns

Domain content and density change between applications. Identity does not.
